# 随机点名器 · 单文件离线网页版

课堂、会议、直播抽人用的「人名球」点名工具。一个 HTML 文件，双击即可用，不联网、不装依赖、不上传任何数据。

- 在线演示（豆包发布版）：https://4m971vpmr3c1r.doubao.link/app/app_17j81wh6x8e
- 源码：`随机点名器.html`（单文件，约 82 KB，内联 CSS / JS，零外部请求）

---

## 一、它是什么

120 个名字按 Fibonacci 球面均匀分布成一颗缓慢自转的 3D 球。点「开始」后球体随机翻转、加速，转出残影；点「暂停」后按设定的圈数减速滑行，停稳即全屏显示被抽中的名字。

整个过程纯 Canvas 2D 渲染 + Web Audio 本地合成音效，没有图片、没有音频文件、没有网络请求。

## 二、主要特性

**抽取**
- 人名球待机自转，抽取时随机方向翻转、随机变速，转速 5–8 倍
- 暂停后按「停止滑动圈数」减速滑行，圈数 0 则立刻停住出结果
- 加权抽取：可为每人设「极高 / 高 / 默认 / 低 / 极低 / 永远抽不到」，权重 8 / 4 / 1 / 0.5 / 0.1 / 0（默认各 1），权重保证合计精确 100%
- 「永远抽不到」的人照常出现在球体上，但永远不会被抽中；若所有人都设成这一档，抽取会自动兜底等概率并在合计行提示
- 实测 120 人时动画稳定 60 fps

**多套配置（v1.7.0 新增）**
- 每套配置**独立保存**自己的名单、隐藏概率与名单外概率项，互不覆盖
- 主页右上角有**可见的胶囊切换开关**：平时用「原版」公开名单，需要时一键切到另一套，切换后球体与抽取立即使用新配置
- 抽奖进行中与结果页展示期间，开关自动禁用，避免误触
- 设置里可切换、重命名、新建空配置、复制当前配置、删除、一键「恢复原版」（120 人示例名单 + 全部等概率）
- 删除到只剩一套时会拦下，保证至少保留一套

**结果页**
- 全屏纯黑背景 + 巨大姓名（单字高度约 30% 视口高），超长姓名自动压到 60% 视口宽仍保持一行
- 左右两个红色退出按钮，停留时长可设 3–60 秒（默认 10 秒）自动返回，最后 3 秒按钮脉冲提示
- Esc 或空格随时退出

**名单**
- 粘贴导入：支持换行、逗号、顿号、空格混用
- 上传 `txt` / `csv`：CSV 只取每行第一列，自动跳过表头与备注
- 名单为空时提示，不会抽出空结果

**设置面板**（隐藏机关进入）
- 通用：配置（多套名单与隐藏概率）、转动速度（0.5–3×）、停止滑动圈数（0–10 圈）、结果停留时长、抽奖音效与音量、名单管理、通用密码、机关手势
- 个性化：装饰密度、背景颜色、背景图片（自动压缩到长边 1600px，本地保存）、图片不透明度、字体族（黑体/宋体/楷体/幼圆/等宽）、字体颜色（可自动适配背景亮度）、标题字号与字重、结果姓名缩放与字重、球体字号
- 默认配置随时「恢复默认」

**隐藏机关与密码**
- 机关是暗色星空装饰里的**蓝色星星**，其余彩色星星都是干扰项
- 默认手势：**单击一次、右侧中部**的那颗蓝星（具体方位可在设置里改成左中/左上/左下/右上/右下/顶部/底部，并支持 1–4 颗星按顺序点、每颗星连点 1–3 次）
- 手势总窗口 20 秒，相邻点击间隔 ≤ 4 秒；中途点错或超时则作废重来
- 通过后弹出密码框：通用密码进入设置面板；高级密码进入「概率加权」页
- 通用密码与高级密码互相独立；连错 3 次锁定 10 秒；在密码标题上连点 5 次（3 秒内）可重置为默认密码
- **首次使用的默认密码是 `123456789`，建议进设置后立刻改成自己的密码**

**音效（无外部文件，全部浏览器本地合成）**
- 开始：一声 0.5 秒气口
- 转动与减速：定时炸弹式「嘀嗒」，越快越密、减速后逐渐变慢
- 出结果：一记低频冲击 + 上行三音阶中奖音
- 密码正确/错误、按钮点击均有独立音效；可一键关闭或调音量，关闭后不会创建音频上下文

**存储**
- 全部状态存在浏览器 `localStorage`：
  - `rollcall.config.v1`：配置 JSON（多套配置及其名单/概率、音效、背景、字体、手势、密码等；旧版单套名单数据会自动迁移为「原版」配置）
  - `rollcall.bgimage.v1`：背景图片（压缩后的 dataURL，与配置分开存，避免重复写入大字符串）
- 换设备、换浏览器、清缓存即恢复初始状态；不会上传到任何服务器

## 三、怎么用

1. 把 `随机点名器.html` 放到任意位置，用 Chrome / Edge / Safari 等现代浏览器双击打开（`file://` 直接可用）。
2. 需要多人同时用时，把文件发给他们，或部署到任意静态托管（它就是单个 HTML）。
3. 点底部「开始」→ 球体乱转 → 点「暂停」→ 减速停住 → 结果页 → 自动/手动返回。

**第一次打开建议**
1. 用默认手势（单击右侧中部蓝星）→ 输入 `123456789` → 进设置
2. 改通用密码、粘贴自己的名单
3. 按需调转度、停留时长、背景与字体

## 四、技术说明

- 单文件、无依赖：CSS 与 JS 全部内联，无 `fetch`、无 CDN、无第三方库
- 球面点阵：Fibonacci 螺旋采样（黄金角 ≈137.5°），名字与点位随机洗牌，避免同姓聚簇
- 渲染：Canvas 2D；逐帧用 `destination-out` 淡出形成 1–2 帧拖影，背景由独立 CSS 图层承担，因此可放纯色或图片
- 性能：背面名字显著降低透明度，正反面按深度排序绘制；120 人 60 fps
- 安全：所有名字均以 `textContent` 写入，杜绝 XSS；无网络请求
- 字体：只用系统字体栈，离线可用
